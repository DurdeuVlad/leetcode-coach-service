# Issue tracker: GitHub

Issues and planning maps live in this repository's GitHub Issues and use `gh`.

Pull requests are not treated as feature-request surfaces.

Wayfinder maps use `wayfinder:map`. Decision tickets use
`wayfinder:research`, `wayfinder:prototype`, `wayfinder:grilling`, or
`wayfinder:task`. Tickets are GitHub sub-issues where supported, use native
dependencies, and are claimed by assignment. Resolutions are recorded as issue
comments before closure, then linked from the map.
